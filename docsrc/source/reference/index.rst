Reference
=========

What a run is made of, one page per part.
Start with :doc:`configurations` to find a key, and with :doc:`tasks` to see what a run does with one.

Running an experiment
---------------------

- :doc:`configurations` is every registration in the toolkit, as searchable cards built from the registry itself.
- :doc:`tasks` is what one experiment does, and what it writes to disk.
- :doc:`metrics` is what each corpus is scored with.
- :doc:`leaderboard` is the results of the MAMKit paper.

Data
----

- :doc:`datasets` is the corpora, their loaders, and the split strategies.
- :doc:`features` is the featurizers that turn text and audio into model inputs.
- :doc:`utilities` is the lower-level layers and helpers that the components call.

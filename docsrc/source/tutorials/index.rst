Tutorials
=========

Two tutorials, in order.

- :doc:`quickstart` runs a registered task end to end on a synthetic corpus, then runs an experiment of the MAMKit paper. It needs nothing but the package.
- :doc:`custom-model` writes an encoder of your own, registers it in a package beside MAMKit, and runs it through the same task.
